RISCOS DO PROJETO

Principais riscos que podem afetar o desenvolvimento e medidas para reduzir seus impactos.

1. Riscos identificados:
- Atraso no desenvolvimento
    Dividir o desenvolvimento em pequenas etapas
    Acompanhar o cronograma
- Erros na API
    Realizar testes dos endpoints
- Problemas no banco de dados
    Validar a estrutura do banco antes da implementação
- Alterações no escopo
    Manter o escopo definido
    Registrar alterações na documentação
- Alteração indevida do código
    Utilizar Git para controle de versão
    Realizar commits frequentes


Os riscos serão revisados durante o desenvolvimento do projeto.
